# Peri-workout Nutrition（運動前後飲食）

## 主題概述
運動前、中、後的飲食策略（Peri-workout Nutrition）旨在最大化訓練表現、加速肝醣補充與促進肌肉修復。核心原則：在對的**時機**攝取對的**食物**。

## 關鍵策略彙整

### 運動前
| 距離訓練 | 策略 |
|---------|------|
| 2–4 小時前有正常進食 + 運動 < 60 分鐘 | 只需補水（CMUH） |
| 1–3 小時前 | 複合碳水 + 少量蛋白質（minimark） |
| 15–30 分鐘前 | 碳水:蛋白質 = 3-4:1，100–200 kcal（CMUH） |

### 運動中
- < 60 分鐘：補水
- > 60 分鐘高強度：30–60g 碳水 / 小時（CMUH）

### 運動後
- 黃金期：前 30–60 分鐘（CMUH）/ 0–45 分鐘（bettermilk）
- 碳水 1–1.2 g/kg + 蛋白質 0.2–0.4 g/kg（CMUH，最具實證）

## 開放問題 / 研究缺口
1. **黃金期的「真實寬度」**：近年研究指出 anabolic window 可能延伸至 2 小時甚至更長；每日總量可能比精確時機更重要（需更多文獻支撐）
2. **碳水化合物漱口法**的效果機制與適用範圍
3. **個體差異**：訓練年資、目標（增肌/減脂/維持）對策略的影響
